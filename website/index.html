FAQ

Common Questions

Is the web version really completely free?+
Yes — 100% free, forever. No credit card, no hidden fees, no trial. Full POS, inventory, CNAM billing, and reports at no cost.
What is the difference between web and desktop?+
The web version runs in your browser and requires internet. It is free. The desktop version is installed on your Windows PC, works offline, and integrates with receipt printers and barcode scanners.
How do I buy the desktop version?+
Contact us via WhatsApp or email. We discuss your needs, explain pricing, and schedule a professional installation. No online payment — everything is handled directly with the seller.
Does PharmaSOFT support CNAM insurance?+
Yes, both versions fully support CNAM billing. Process insured prescriptions, track reimbursements, and generate CNAM reports.
Can multiple staff use it at the same time?+
Yes. Create multiple user accounts with different roles — cashier, manager, or admin. Each person logs in separately and all activity is tracked.
Is my data safe?+
Web version data is encrypted and backed up to secure cloud servers. Desktop data is stored locally, giving you full control. You can export data anytime.
What OS does the desktop version support?+
Currently Windows 10 and Windows 11. Our team handles the full installation and configuration on your machine.
